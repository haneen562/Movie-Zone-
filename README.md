# 🎬 Movie Zone

A movie search and discovery app built with JavaScript and the TMDB API.

## 🔗 Live Demo
[View Live](https://github.com/haneen562/Movie-Zone-)

## ✨ Features
- Real-time movie search using TMDB API
- Dynamic content rendering without page reload
- Movie details: title, rating, release year, and overview
- Responsive design for all screen sizes
- Clean, modern UI

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- TMDB API (Fetch API)

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/haneen562/Movie-Zone-`
2. Open `index.html` in your browser
> ⚠️ Note: You may need a free TMDB API key from [themoviedb.org](https://www.themoviedb.org/settings/api)
